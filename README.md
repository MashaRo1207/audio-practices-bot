# Бот с аудиопрактиками

Telegram-бот на Python (aiogram 3), который предлагает пользователю выбрать
одну из 20 аудиопрактик по 4 категориям: **Сон**, **Стресс и тревога**,
**Фокус и продуктивность**, **Энергия и бодрость**.

Пользователь сначала выбирает категорию, потом практику внутри неё — бот
присылает аудиофайл с описанием. Пока аудиофайл ещё не добавлен, бот
присылает текстовое описание практики с пометкой «аудио скоро появится»,
так что ботом можно пользоваться и тестировать его до того, как все записи
будут готовы.

## Структура проекта

```
audio_practices_bot/
├── bot.py              # основная логика бота
├── practices.py        # данные: категории и 20 практик
├── audio/               # сюда кладутся mp3/ogg файлы с практиками
├── requirements.txt
├── .env.example
└── README.md
```

## Быстрый старт (запуск локально)

1. Получите токен бота:
   - откройте в Telegram чат с **@BotFather**
   - отправьте `/newbot` и следуйте инструкциям
   - скопируйте выданный токен вида `123456789:AA...`

2. Установите зависимости (Python 3.10+):

   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` на основе `.env.example` и вставьте туда токен:

   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

4. Запустите бота:

   ```bash
   python bot.py
   ```

5. Откройте бота в Telegram и отправьте `/start`.

## Добавление аудиозаписей

Список практик и нужных имён файлов — в `practices.py`, поле `"file"`
у каждой практики (например, `sleep_01.mp3`). Просто положите файл с
таким именем в папку `audio/` — бот подхватит его автоматически, без
перезапуска кода не потребуется ничего менять, только положить файл
(бот проверяет наличие файла при каждом запросе).

Поддерживаются любые форматы, которые принимает Telegram для аудио
(mp3, m4a, ogg и т.д.), главное — чтобы расширение в имени файла
совпадало с тем, что указано в `practices.py`.

## Как добавить/изменить практики

Откройте `practices.py` — там простой словарь `CATEGORIES`. Можно:
- изменить название, описание, длительность существующей практики;
- добавить новую практику в любую категорию (скопируйте блок с
  практикой, поменяйте id, title, description, duration, file);
- добавить новую категорию — скопируйте блок категории целиком.

Бот сам подхватит любые изменения при следующем перезапуске.

## Варианты деплоя (когда решите, где размещать бота)

Бот работает в режиме polling (`dp.start_polling`), поэтому подойдёт
почти любой хостинг, который может держать процесс запущенным
24/7:

- **VPS** (например, timeweb, selectel, DigitalOcean) — самый гибкий
  вариант. Запустить `python bot.py` через `systemd`, `screen`/`tmux`
  или Docker.
- **Railway / Render** — можно задеплоить репозиторий с этим кодом,
  указать команду запуска `python bot.py` и добавить переменную
  окружения `BOT_TOKEN` в настройках проекта. Бесплатных тарифов
  может не хватить для 24/7-работы без «засыпания» — уточните
  условия перед стартом.
- **Docker** (если понадобится) — можно обернуть в простой
  `Dockerfile` на основе `python:3.11-slim`, `pip install -r
  requirements.txt`, `CMD ["python", "bot.py"]`.

Если решите, на чём деплоить — помогу подготовить конкретный конфиг
(Dockerfile, systemd-unit, railway.json и т.п.).
